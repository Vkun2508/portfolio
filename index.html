Hybrid ISP

A smartphone camera pipeline: classical stages plus a compact neural denoiser, run only as much as each photo needs.

Nov 2026Team of 41st place, RVU Computer Vision HackathonPython, FastAPI, React, TypeScript, ONNX, Docker

What I built

  • The hybrid pipeline design: classical camera stages, a compact neural denoiser, and the router that saves compute on easy photos.
  • A FastAPI service and a React + TypeScript app that run uploaded photos through three pipelines and show quality scores and per-stage timings. Deployed with Docker.
  • The evaluation suite: 26 held-out images from 5 phones, plus an ablation study.
Try the live demo Read the code

LegalLens

Reads a contract and flags the clauses that could hurt you, with the matched phrase and its character range.

Oct 2026NLPPython, FastAPI, pypdf, pytest

What I built

  • Splits contracts (PDF or text) into clauses and flags each one, returning the matched phrases with character offsets.
  • Ships as a FastAPI web app, a JSON API with input validation and size limits, and a CLI.

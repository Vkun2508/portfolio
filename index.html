Hybrid ISP

A smartphone camera pipeline that won 1st place at RV University's Computer Vision Hackathon 2026.

Nov 2026Team of 4Python, FastAPI, React, TypeScript, ONNX, Docker

What I built

  • Designed the hybrid pipeline: classical camera stages plus a compact neural denoiser, with an adaptive router that decides per photo how much of the network to run.
  • Built a FastAPI service and a React + TypeScript web app that run uploaded photos through three pipelines and show quality scores and per-stage timings. Deployed with Docker.
  • Built the evaluation suite: 26 held-out images from 5 phones, plus an ablation study.
